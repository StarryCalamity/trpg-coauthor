# v0.1.0 — 初始交付

中文TRPG模组共同创作技能，包含：

- 情境与时间线、调查线索、日常与社交、NPC与对白、遭遇与规则、文字修订和运行审查。
- 事件卡和NPC卡模板。
- 来源、改编说明与完整许可。
- 安装说明、具体设计推演记录、自动结构校验与打包流程。

下载文件：

- `trpg-coauthor.zip`：独立技能包，解压后保留整个技能目录。
- `trpg-coauthor-plugin.zip`：包含可移植`plugin.json`和技能目录的分发包。
- `SHA256SUMS.txt`：两个ZIP的SHA-256校验值。

格式、相对引用、包内独立性和解压完整性已检查。创作方法仅经过人工设计推演，尚未经过独立模型评测、实际带团或插件目录审核。

技能包不需要执行脚本、额外AI技能、MCP服务或专用运行时。仓库中的Python脚本仅用于维护与发布。
